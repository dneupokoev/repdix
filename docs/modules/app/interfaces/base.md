# app/interfaces/base.py

## Назначение модуля
Модуль задаёт базовые интерфейсы и DTO для адаптеров мессенджеров. Он определяет общий контракт взаимодействия между ядром приложения и конкретными реализациями мессенджеров: входящие сообщения, ответы ядра и обязательные методы адаптера.

Версия файла: `261029.05`.

## Основные классы и методы

### `ChatMessage`
DTO входящего сообщения от пользователя.

Аргументы:
- `user_id: str` — идентификатор пользователя.
- `chat_id: str` — идентификатор чата.
- `text: str` — текст сообщения.
- `status_callback: Optional[Callable[[str], Awaitable[None]]]` — необязательный асинхронный callback для передачи статуса; принимает строку. По умолчанию `None`.

### `ChatResponse`
DTO ответа ядра для отправки пользователю.

Аргументы:
- `text: str` — текст ответа.
- `image_path: Optional[str]` — необязательный путь к изображению.
- `reply_markup: Any` — необязательная Inline-клавиатура. Ядро не зависит от `aiogram` и передаёт её «как есть» — например, `dict` формата Telegram `{"inline_keyboard": [...]}`; адаптер сам решает, как её отправить. По умолчанию `None`.

### `BaseChatInterface`
Абстрактный интерфейс адаптера мессенджера. Наследники обязаны реализовать методы ниже.

Методы:
- `async start(self) -> None` — запуск адаптера: подключение, цикл событий и т.п.
- `async send_message(self, chat_id: str, text: str) -> None` — отправка текстового сообщения в чат.
- `async send_image(self, chat_id: str, image_path: str) -> None` — отправка изображения в чат.

## Зависимости
Импортируются только стандартные модули Python:
- `abc.ABC`, `abc.abstractmethod` — для абстрактного базового класса.
- `dataclasses.dataclass` — для DTO.
- `typing.Any`, `typing.Callable`, `typing.Awaitable`, `typing.Optional` — для аннотаций типов.

Зависимостей от других модулей проекта в файле нет.

## Использование в проекте
В предоставленном изолированном файле нет импортов и вызовов из других модулей проекта, поэтому конкретные места использования не видны.

По назначению модуль является контрактом: адаптеры мессенджеров должны наследовать `BaseChatInterface` и реализовывать `start`, `send_message`, `send_image`; ядро и адаптеры могут использовать `ChatMessage` и `ChatResponse` для передачи входящих сообщений и ответов. `ChatResponse.reply_markup` при этом передаётся адаптеру без привязки ядра к конкретной библиотеке мессенджера.
